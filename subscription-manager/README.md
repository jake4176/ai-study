# 구독 매니저

구독을 한곳에 모아 지출을 보이게 합니다. 가입한 사람은 자기 구독만 봅니다.

## 범위

- 화면: 구독 목록, 월 지출 대시보드, 결제일 알림
- 기능: 구독 기록, 월 지출 합산과 차트, 결제일 D-day 알림
- 데이터: 구독 이름, 금액, 통화, 결제 주기, 결제일. 매년 결제는 월이 더 필요합니다. 계정과 푸시 구독은 각자 보기와 폰 알림에 필요합니다.
- 만들지 않음: 지출 조언, 절약 추천, 카드 연동, 가족 공유, 다크 모드

결제일과 “오늘”은 서울 시간 기준입니다. 알림은 결제 당일과 하루 전입니다.

## 실행

```bash
npm install
npm test
npm run dev
```

브라우저에서 `http://127.0.0.1:5173` 을 엽니다. 가입한 뒤 구독을 기록합니다.

폰 알림은 사이트를 홈 화면에 추가하고 알림을 허용해야 합니다. 아이폰은 홈 화면에 추가한 웹 앱에서만 백그라운드 알림이 동작합니다 (iOS 16.4 이상).

```bash
npm run build
npm start
```

운영 모드 주소는 `http://127.0.0.1:8787` 입니다. 데이터는 `data/app.sqlite` 에 있습니다.
